# Software Engineering Diagrams Viewer

A responsive React web application to browse, inspect, and swipe through Software Engineering **Activity Diagrams** and **State Chart Diagrams**.

## ✨ Features
- **Navbar Navigation**: Switch between **Activity Diagrams** and **State Chart Diagrams** with one click.
- **Swipeable Carousel**: Swipe left/right on mobile or use arrow keys / on-screen buttons to glide through 10 diagrams of each type.
- **Correct Orientation**: All 20 diagrams from the PDFs were extracted, processed, straightened, and oriented upright with high clarity.
- **Interactive Controls**:
  - Zoom in / Zoom out (up to 300%) with reset
  - Fullscreen view mode
  - High-Definition (HD) PNG download button
  - Bottom thumbnail filmstrip to jump directly to any of the 10 systems
- **10 Software Engineering Systems Covered**:
  1. College Laboratory Management System (Issue Equipment)
  2. Library Management System (Book Issue and Return)
  3. Hospital Management System (Patient Appointment)
  4. Student Information System (Marks Entry)
  5. Online Food Ordering System (Place Order)
  6. Online Shopping System (Purchase Product)
  7. Banking Management System (Money Transfer)
  8. Hotel Management System (Room Reservation)
  9. College Placement Management System (Job Application)
  10. Examination Management System (Result Generation)

## 🚀 Deploying to Vercel
1. Import this repository into Vercel.
2. Framework Preset: **Vite** (automatically detected).
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!

## 💻 Local Development
```bash
npm install
npm run dev
```
